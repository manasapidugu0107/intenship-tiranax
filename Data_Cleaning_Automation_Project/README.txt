Data Cleaning & Reporting Automation Project

This project focuses on automating data cleaning and reporting tasks using Python.

Tools Used:
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

Project Tasks:
- Loading dataset
- Checking missing values
- Removing duplicate data
- Fixing inconsistent values
- Generating automated reports
- Creating visual charts

Files Included:

2. cleaned_data.csv
3. automated_report.csv
4. data_cleaning_automation.ipynb
5. project_report.docx
6. README.txt

Outcome:
Learned data preprocessing, automation, and reporting workflow using Python.
