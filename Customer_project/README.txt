Customer Segmentation Project

This project performs customer segmentation using K-Means clustering.

Files included:
- Mall_Customer.csv (dataset)
- segmented_customer.csv (output data)
- Customer_Segmentation.ipynb (Python notebook)
- Customer Segmentation Project Report (project documentation)

Tools used:
Python, Pandas, Matplotlib, Scikit-learn

Goal:
To divide customers into groups based on income and spending behavior.
